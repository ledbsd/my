Mixin — это вспомогательный класс, который добавляет 
поведение или функциональность к другим классам через 
наследование, но не предназначен для самостоятельного 
использования

Признаки Mixin:
- не используется сам по себе
- не хранит состояние / нет __init__
- добавляет поведение
- лучше в имя класса добавить суффикс Mixin

Как работает:
- выносим в него общие методы
- задаем перемнные класса для перекрытия self.args
- выставляем вторым в наследовании
